# My Favourite Technology
1. ## MCP(Model Context Protocol)
    This is a game changer for large LLM models as for agentic workflows we need to connect tools, before MCP we use API where for a task that is done correctly gives output correctly but how about our API stop giving response then LLM gives Hallucinated result, there are many other reasons of prefering MCP instead of API for LLM as I discussed one of them.
    [MCP_docs](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)
---
2. ## FastApi:
    I like the Api framework as it uses WSAGI for fast data transformation and uses asynchronous working system this is the reason it makes fast from other frameworks like RESTAPI.
    [fast_api_docs](https://fastapi.tiangolo.com/)
---
3. ## Redis:
    I Like this technology as it fastens the user interaction with software where in past we need to wait for quering large amount of data Redis an in build temporary fast database make it easier to use.
    [redis_docs](https://redis.io/docs/latest/)
---
4. ## Langgraph:
    I like this technology as we can easily make our custom Node to Node agentic workflow system by this, though there is **n8n** where we donot code and make workflows but in python we have a bit higher control on our workflow state , parsing , limiting area and invokations.
    [langgraph_docs](https://docs.langchain.com/oss/python/langgraph/overview)
---
5. ## Generative AI:
    This include a large amount of systems like context driven systems, image related systems but the one that I like is **RAG** systems where we bound our llm to answer only those questions that are in our data, this is a blessing for those companies which donot want to give their data to public AI like claude , GPT or other public systems, now they are able to build their own Chatbots by these technologies.
    [RAG_Paper](https://arxiv.org/pdf/2005.11401)
